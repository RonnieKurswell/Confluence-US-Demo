# Video slots

Drop an MP4 here named after the value pool and it appears automatically in that
pool's panel — no code change needed. Anything missing falls back to a marked
placeholder tile.

| File                                       | Value pool                   |
| ------------------------------------------ | ---------------------------- |
| `ai-strategy-engineering.mp4`              | AI Strategy & Engineering    |
| `data-for-ai.mp4`                          | Data for AI                  |
| `process-ai.mp4`                           | Process AI                   |
| `agentic-legacy-modernization.mp4`         | Agentic Legacy Modernization |
| `physical-ai.mp4`                          | Physical AI                  |
| `ai-trust.mp4`                             | AI Trust                     |

Specs: H.264 MP4, 16:9, 1080p or 720p, **no audio track** (kiosk plays muted and
looped), ideally 10–20 seconds. Keep each file under ~15 MB so the booth machine
can run fully offline.
